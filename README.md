# Notch (Markus Persson) — Blocky Universe Scroll Site

PPT(6枚)をそのまま1ページのスクロールアニメーションWebサイトにしたものです。

## 特徴
- 下にスクロールするとスライド1〜6が切り替わります(スライド間はグラデーションで境目なし)
- スクロールに合わせて**草ブロック・木材・TNT・ダイヤモンド・金ブロック・葉っぱ**などが降ってきます
- **画面をクリック/タップした場所からもブロックが飛び出します**
- スクロールが速いほどブロックが大量に降る「スクロールブースト」付き
- スライドごとに演出が変化:
  - 1枚目: 夕焼け・回転する草ブロック・タイトルがブロックのように落下積み上げ
  - 2枚目: Commodore 128(CRT画面+カーソル点滅)・揺れる木の看板
  - 3枚目: 洞窟・タイピングされる「RAW CODE」・クラフト格子・輝くダイヤ・ネオン看板
  - 4枚目: 金/青のブロック枠・数値カウントアップ(300 million / $2.5 billion)・流れる雲
  - 5枚目: **提供いただいた画像をそのまま背景に使用**(光の反射演出)
  - 6枚目: 「NEVER STOP CRAFTING」が文字ごとに落下スラム→画面シェイク+TNTが地面で爆発
- PPTの内容のみ表示(追加テキストなし)
- 外部ライブラリ不使用(単一 `index.html`)
- `prefers-reduced-motion` 対応 / スマホ・タブレット対応

## 公開方法(GitHub Pages)
1. リポジトリの **Settings → Pages**
2. Source: **Deploy from a branch** / Branch: `main` / フォルダ: `(root)` → **Save**
3. 数分後 `https://ykrhositukir.github.io/Egacrafting/` で公開されます

## Note
スライド5の画像は外部CDNのURLを直接参照しています(期限付きトークン付き)。
長期運用する場合は画像をダウンロードして `assets/slide5.png` などに保存し、
`index.html` 内の `<img class="s5-bg">` の `src` を差し替えてください。
(画像が読み込めない場合は、自動でグラデーションのフォールバック背景が表示されます)
